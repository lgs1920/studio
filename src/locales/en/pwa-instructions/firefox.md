**Firefox** does not support automatic Progressive Web App (PWA) installation like Chrome or Edge. To add **LGS1920 Studio** to your device:

1. Open **Firefox** and navigate to the LGS1920 Studio website.
2. For desktop, consider bookmarking the website for quick access:
   - Click the **star icon** in the address bar to save it.
3. For mobile, you can add it to your home screen manually:
   - On Android: Use the browser menu to select **Add to Home screen** if available, or use **Chrome** for full PWA support.
   - On desktop: Create a shortcut by dragging the address bar URL to your desktop.
4. For the best experience, we recommend using **Chrome** or **Edge**, which support automatic PWA installation.
