**Firefox** does not support automatic Progressive Web App (PWA) installation like Chrome or Edge. To add **LGS1920
Studio** to your device:

1. For desktop, consider bookmarking the website for quick access:
    - Click the **star icon** in the address bar to save it.
2. For mobile, you can add it to your home screen manually:
    - On Android: Use the browser menu to select **Add to Home screen** if available, or use **Chrome** for full PWA
      support.
    - On desktop: Create a shortcut by dragging the address bar URL to your desktop.

For the best experience, we recommend using **Chrome** or **Edge**, which support automatic PWA installation.

Firefox does not provide the same automatic installation and update flow. If Studio is installed through a supported
browser, updates are reported in the Studio dialog and the application restarts after an update is complete.
