## Studio 1.0.0 — Replay Recording, Timeline Editing, Deployment Reliability, and Optional Cesium ion

## Release Scope

- Studio 1.0.0
- Backend 0.8.0
- Site 2026-09-13

## New Features and Improvements

### studio

- Replay Timeline editing and playback now combine zoom, fit, track visibility, snapping, playhead following, and batched controlled updates while preserving the user's view.
- Timeline playback now coalesces frame synchronization, skips unchanged playhead updates, and keeps the playhead visible near the viewport edges.
- Timeline preparation now uses a normalized projection with synchronized track actions, grouped widget clips, generic track creation, protected track removal, and a branded locked preview.
- Timeline menus and interactions remain reliable inside Shadow DOM and during crop-zone/map interaction changes.
- Replay recording now separates standard and synchronized workflows, preserves journey metadata, and uses a stable camera/frame pipeline with crop and terrain safeguards.
- Replay capture now preserves widget dimensions, supports non-distorting resize, waits for visible imagery and tiles, and handles rehydrated widgets and asynchronous canvases.
- Replay video tooling now includes a recording monitor with Picture-in-Picture fallback, standalone crop recording, synchronized styling, and grouped recording controls.
- Studio layout and onboarding now include resizable drawers, persistent initialization feedback, hide/show widget controls, updated welcome media, and improved PWA installation/update handling.
- Studio diagnostics and attribution now cover structured runtime errors, provider-specific credits, photography, Three.js, and backend initialization support details.
- Cesium ion remains optional, while local cleanup on close, launch storage, and backend SMTP process isolation provide safer runtime and deployment behavior.

See [Studio changes from 1.0.0-beta.3 to 1.0.0](https://github.com/lgs1920/studio/compare/1.0.0-beta.3...1.0.0) and [the additional Timeline changes prepared for this draft](https://github.com/lgs1920/studio/compare/v1.0.0...d3c382c482296d2bc87bfab94d2fd64cf085d95f) on GitHub.

### backend

- Rendered localized form emails are accepted through a generic backend mail envelope.
- Launch registration now supports confirmation, resend, cancellation, and persistence outside release directories.
- Backend administration commands can list pending registrations and clear selected registrations with scoped actions.
- Visitor acknowledgement and support messages are separated, with site links derived from deployment configuration.
- Backend statistics APIs now provide real-time counts and historical period data.
- Backend deployment monitoring now checks liveness every five minutes and can perform a controlled PM2 restart after a confirmed outage.
- Backend PM2 processes now use persistent rotating error logs, with monitoring and restart results recorded without exposing secrets.
- The obsolete FFmpeg video-conversion pipeline has been removed from the backend integration.
- Backend deployment now uses PM2 7.0.4 for process management.

### site

- Help, Contact, Launch Registration, confirmation, cancellation, and revocation routes now share localized content, access rules, responsive layouts, and clearer guidance.
- Contact and registration forms now use consistent status handling, scoped diagnostics, localized mail catalogs, and pending-registration resend support.
- Public statistics now combine live counters with historical charts, and public releases are ordered and paginated in the changelog.
- Site backend integration now reads configured endpoints and provides a scoped recovery dialog when the backend is unavailable.
- Site search now supports guide-scoped queries, localized result categories, highlighted matches, and 404 handoff to the global dialog.
- Help navigation, breadcrumbs, homepage content, and guide entry points now provide clearer localized access to the main site areas.
- Hero presentation now combines rotating media catalogs, animated neon routes with a non-WebGL fallback, refreshed branding, and improved spacing.
- English and French Studio, registration, privacy, and access content now remain aligned across responsive layouts.
- Credits pages and footer links now expose the relevant Studio, media, and open-source attribution information.
- The FAQ now includes the Grande Sûre story and its accompanying photo.

See [Site changes from the previous release reference](https://github.com/lgs1920/site/compare/682d1bc74c96493005999cf226e5033ff0f18ae1...c6aeacf5c7715b0152a25c4a0c5a507e31e44e77) on GitHub.
