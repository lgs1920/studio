## Studio 1.0.0 — Replay Video Creation, Privacy-First Caching, and a More Flexible Workspace

## Release Scope

- Studio 1.0.0
- Backend 1.0.50
- Site 2026-11-06

## New Features and Improvements

### studio

- Journey video creation now centers on Replay MP4 export. Preparation, camera tracking, timeline-aligned clips, grouped and multiple content widgets, and dry-run preview make composition and review more consistent.
- Replay recordings preserve the prepared camera, crop, tracks, POIs, widgets, and imagery more reliably while keeping the main map view independent.
- Import Garmin and Strava activity files in FIT or TCX format, preserving routes, timestamps, elevation, and available activity data without a provider connection.
- Journey and POI editing now includes local GPX route corrections, location-aware timestamps, configurable POI details, consistent creation tools, and device-based location search.
- Large local databases load progressively. The privacy-first tile cache separates credentialed provider data and clears private cache entries when credentials change or local profile data is removed.
- The workspace and PWA flows are more flexible, with dockable, detachable, resizable, and grouped widgets, clearer installation controls, and persistent update handling.

### backend

- Backend services combine localized contact and registration flows with binary-safe FIT and TCX delivery, automated deployments, health checks, rotating logs, and controlled recovery.

### site

- The localized 1.0 site brings together the Help guide, local search, contact and registration forms, historical statistics, animated page headers, banner media, and a configurable countdown.

See [Studio changes from 1.0.0-beta.4 to 1.0.0](https://github.com/lgs1920/studio/compare/1.0.0-beta.4...1.0.0) on GitHub.
