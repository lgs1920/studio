# 1.0.0-beta.2 - 2026-06-14

## Orbit, Panorama, and Flythrough

- **Orbit shortcut**: `Alt+Shift+O` now launches Orbit, replacing the former launch shortcut.
- **Orbit and panorama widget toggles**: `Alt+O` toggles the Orbit widget bar while Orbit is running, and `Alt+P` does the same for Panorama while Panorama is active.
- **Journey toolbar orbit state**: The Orbit button in the journey toolbar now stays animated while an Orbit is active, including when Orbit was started from the main UI button.
- **Journey toolbar stop behavior**: Clicking the journey toolbar Orbit button now stops the current Orbit without immediately relaunching it.

## Flythrough clips

- **Inline clip editing**: Flythrough clip editing now happens directly inside the drawer with `WaDetails`, instead of a popup.
- **Dynamic clip lists**: Start and stop clip lists now support dynamic add and remove actions.
- **Clip icons**: Flythrough clip titles now show their dedicated icon in the YAML catalog and in every UI title presentation.
- **Clip naming**: The former `launch` clip has been renamed to `take-off`.
- **Scale removal**: Flythrough scale handling has been removed from the UI and from the underlying code path.

## UI and behavior

- **Flythrough drawer rules**: The main UI is hidden from the start clips until the stop clips finish, while the Flythrough toolbar itself stays available.
- **POI animation continuity**: POI animation updates continue to run correctly while the main UI is hidden during Flythrough playback.
- **Toolbar visibility**: The button that opens the Flythrough drawer is hidden during an active Flythrough, while the rest of the Flythrough toolbar remains visible.
