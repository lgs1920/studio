## Studio 1.0.0 — Replay Recording, Timeline Editing, Deployment Reliability, and Optional Cesium ion

## Release Scope

- Studio 1.0.0
- Backend 0.8.0
- Site 2026-09-14

## New Features and Improvements

### studio

- Replay Timeline editing and playback now combine zoom, fit, track visibility, snapping, playhead following, and batched controlled updates while preserving the user's view.
- Timeline preparation now uses a normalized projection with synchronized actions, grouped widget clips, generic track creation, protected track removal, and a branded locked preview.
- Timeline menus and interactions remain reliable inside Shadow DOM and during crop-zone/map interaction changes.
- Replay recording now separates standard and synchronized workflows, preserves journey metadata, and uses a stable camera/frame pipeline with crop and terrain safeguards.
- Replay capture and video tooling now preserve widget dimensions, wait for visible imagery, handle rehydrated widgets, and provide monitor, Picture-in-Picture, crop, and styling controls.
- Studio layout, onboarding, and PWA behavior now include resizable drawers, initialization feedback, hide/show controls, updated welcome media, and update handling.
- Studio diagnostics, attribution, optional Cesium ion, local cleanup, launch storage, and backend process isolation now provide safer runtime behavior.

See [Studio changes from 1.0.0-beta.3 to 1.0.0](https://github.com/lgs1920/studio/compare/1.0.0-beta.3...1.0.0) and [the additional Timeline changes prepared for this draft](https://github.com/lgs1920/studio/compare/v1.0.0...d3c382c482296d2bc87bfab94d2fd64cf085d95f) on GitHub.

### backend

- Backend mail, launch registration, administration, and visitor acknowledgement flows now share localized envelopes, scoped actions, persistence, and cancellation support.
- Backend statistics now provide live counts and historical period data.
- Backend deployment monitoring now checks liveness, records rotating PM2 logs, and can perform a controlled restart after a confirmed outage.
- The obsolete FFmpeg video-conversion pipeline has been removed from the backend integration.
- Backend deployment now uses PM2 7.0.4 for process management.

### site

- Help, Contact, Launch Registration, confirmation, cancellation, and revocation routes now share localized content, access rules, responsive layouts, and clearer guidance.
- Contact and registration forms now use consistent status handling, scoped diagnostics, localized mail catalogs, and pending-registration resend support.
- Public statistics and the changelog now provide live/history views, pagination, and publication ordering.
- Site backend integration and search now provide configured endpoints, recovery feedback, guide-scoped queries, localized categories, and 404 handoff.
- Help navigation, breadcrumbs, homepage content, and English/French Studio, registration, privacy, and access content now remain aligned.
- Hero presentation, credits, footer links, and FAQ content now provide refreshed branding, media attribution, neon-route fallback, and the Grande Sûre story.

See [Site changes from the previous release reference](https://github.com/lgs1920/site/compare/682d1bc74c96493005999cf226e5033ff0f18ae1...c6aeacf5c7715b0152a25c4a0c5a507e31e44e77) on GitHub.
