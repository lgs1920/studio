## Studio 1.0.0 — Video Creation Overhaul, Faster Rendering, and a More Flexible Workspace

## Release Scope

- Studio 1.0.0
- Backend 0.8.0
- Site 2026-09-22

## New Features and Improvements

### studio

- Video creation has been redesigned around Replay preparation, separate standard and synchronized recording flows, grouped widgets, and reliable recording controls.
- Replay exports now preserve camera, crop, widgets, imagery, metadata, and visual effects more reliably.
- Map and track rendering now draw more efficiently, keep interaction responsive, and improve startup loading.
- Widgets can be resized, docked, detached, grouped, reordered, hidden, and recovered in a more flexible workspace.
- Startup, PWA updates, welcome screen, provider credits, diagnostics, and local-data cleanup are more reliable.

### backend

- Backend services now provide contact and launch-registration flows, localized mail handling, statistics, liveness checks, logs, and controlled recovery.

### site

- The site now provides its 1.0 content, Help, local search, statistics, forms, media catalog, and refreshed page headers.

See [Studio changes from 1.0.0-beta.3 to 1.0.0](https://github.com/lgs1920/studio/compare/1.0.0-beta.3...1.0.0) and [the additional Studio changes prepared for this draft](https://github.com/lgs1920/studio/compare/v1.0.0...850f1098e8324dcef23c57b7c24e730d5107cdc3) on GitHub.
