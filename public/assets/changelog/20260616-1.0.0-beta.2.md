### Orbit, Panorama, and Flythrough

- Orbit and panorama controls were streamlined, with the flythrough drawer staying available during playback.
- Flythrough clips are now edited directly in the drawer, with cleaner clip management and playback behavior.
- Flythrough playback keeps the main UI hidden when needed, while POI updates continue to run.

### Text Widget

- Text alignment now updates immediately when the content switches between single-line and multiline.
- The text widget now stays reactive while editing, so the selection frame follows content changes in real time.
- Text sizing, padding, and preview rendering are kept consistent across scaled and unscaled states.
- The previewer keeps its vertical centering while respecting the actual text box size.

### UI and Behavior

- Ground offset and fixed altitude values now stay stable during flythrough playback.
- Changelog loading remains paginated and ordered.
- Text widget editing is more stable overall.
