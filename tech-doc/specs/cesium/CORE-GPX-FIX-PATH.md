# Manual GPX path corrections

Fix Path lets a user correct a route locally in map space and adjust the elevation used by the profile. Open it from the map point context menu or press `F` when the current Journey has tracks. The source GPX remains unchanged; validated edits are stored on the Journey and applied as derived track content.

## Editing a Journey

Opening Fix Path temporarily hides the Journey Toolbar and restores its previous visibility on exit without changing the saved setting. Cesium navigation remains available while the user selects a route or correction point. Hold Shift and drag to draw the initial screen rectangle; ordinary map gestures remain available, and pan and zoom remain under user control throughout editing. Selecting an area, activating a section, or selecting a point never moves or reframes the camera. Rotation, tilt, and free-look are locked after a point is selected. The screen rectangle selects visible source vertices across every track in the current Journey. The scan and terrain-visibility checks run in small batches so a long GPX does not block the interface. Selected source squares are combined into SVG path geometry rather than rendered as one DOM element per vertex. Once a source vertex belongs to a section, its white source-square marker is replaced by the section point marker; resetting a moved point returns it to an unmodified section point. The area is selected once per editor session; close and reopen Fix Path to choose another area.

The editor stores every source vertex between a section's endpoints as a section point, including vertices that have not been fixed or removed. The active section's points are magenta and inactive sections' points are gray; clicking an inactive point activates its section. A dashed line previews the corrected route. Source vertices inside a section are represented by its section points instead of duplicate white source squares. Both fixed and unmodified section points can be selected and dragged. Sections whose endpoints are consecutive route vertices merge automatically, including adjacent sections found in saved Journey data. Dragging a source vertex beside existing corrections also merges the affected local sections and retains their point states. To extend a section or merge sections across a gap, Alt+Shift-click a point in the first section, add correction locations if needed, then finish on a later point. Every route point between the selected endpoints becomes a member of the merged section. A right-click on a correction point offers Remove. To create a section, choose a source square, click one or more locations on the map to define the corrected route, then choose a later source square on the same track segment. Corrections are split into local sections so a single edit cannot span an unexpectedly long part of the route. The default source-route limit is 500 m. Application Settings lets the user change it from 50 m to 5,000 m in 10 m steps; the preference is retained when settings are synchronized with defaults.

The Fix Path panel is a draggable scene widget. It displays one active section at a time. The header's left and right chevrons move through sections in Journey travel order, loop at either end, and are hidden when fewer than two sections exist. Sections created while the editor is open immediately join this navigation order. Clicking a gray map point activates its section. Selecting a saved correction point exits section drawing so later map clicks cannot add stray control points. When marker hit areas overlap, the closest visible marker receives the selection and drag. Corrections from every track remain visible and are saved together when validated.

New correction points use the current Cesium terrain height beneath their clicked coordinates when available. Each active section's list includes all its points and has Lat, Lon, and Height columns without Journey or segment labels. The list scrolls independently inside the widget. Clicking a row selects its corresponding map point. A plain click selects one point; Shift-click selects the inclusive ordered range from the anchor point; Ctrl/Cmd-click adds or removes any individual point. Selected map points are larger and outlined, and the panel reports the selection count. With the widget focused, Ctrl+A selects all non-removed points in the active section. Dragging any selected point moves the whole selection by the same map and height offset. Lat and Lon are read-only text fields. Height is an editable whole number in metres, with no numeric spinner. Reset restores a source vertex to its unmodified state or returns a saved point to its stored coordinate. Remove marks a point as removed: the point stays in section data, disappears from the map, and no longer guides the correction. Reset restores a removed point. The active section can be deleted from the header when at least two points are selected; removing every point from a section also deletes that section.

Validate stores the Journey edits, enables them when at least one correction remains, and closes the editor once persistence succeeds. The route redraw and Journey-statistic recalculation then complete independently of the closed editor. Cancel discards the unvalidated draft. Validated corrections are loaded the next time the Journey is opened, remain visibly distinct from source vertices, and can be moved or removed in a later editing session.

## Stored data

`fixPathCorrectionData` contains a revision and correction sections grouped by track slug. Each section records the source geometry segment and endpoint indices, a fingerprint of the covered source coordinates, and ordered points. Every point stores its route progress, `[longitude, latitude, height?]`, and `fixed` and `removed` booleans. Source vertices also store their source index. A point's membership in a section is independent of its flags. Unfixed points remain listed and drawn but do not guide the curve; fixed, non-removed points are interpolation anchors. Removed points are hidden and excluded from the interpolation. Coordinates without an explicit height inherit a height interpolated from the source GPX profile. Legacy points without flags normalize to `fixed: true` and `removed: false`.

The fingerprint prevents a correction from being applied to a different route after the source track changes. Stale sections are skipped rather than moved to new source indices. Multiple sections on a track must be separate, non-overlapping, and separated by at least one unassigned route point.

## Applying edits

The interpolation creates a smooth, Catmull–Rom curve in a local horizontal projection and interpolates elevation through the same ordered anchors. Unfixed source vertices inside a section are recalculated from its fixed anchors. Section endpoints are editable and can also be fixed anchors. Timestamps, extra coordinate dimensions, properties, and the original GPX feature remain intact. This keeps the original track as the persistent source while statistics and display use the corrected derived feature.

`getCorrectedTrackContent()` is the shared source for Journey metrics, Cesium rendering, and Replay path sampling. The `fixPathEnabled` Journey flag applies all saved track corrections or none. Saving an edit increments the correction revision so rendered geometry and Replay samplers refresh. Ordinary load and Replay do not start terrain analysis or asynchronous correction work.
