# Font Awesome Configuration

## Integration

- **Method:** Web Awesome `WaIcon` React wrapper with the shared Font Awesome definition registry and Web Awesome's default resolver.
- **Version:** Font Awesome packages 7.3.1; Web Awesome 3.14.0.
- **License:** Pro.
- **Kit ID:** `eb5c406148` (custom icons and the default CDN resolver).
- **Families:** classic, duotone, brands.

## Defaults

- **Style:** regular for the camera adjustment overlay.
- **Family:** classic.

## Import Pattern

```jsx
import { WaIcon } from '@awesome.me/webawesome/dist/react'

<WaIcon name="ruler-vertical" variant="regular" />
<WaIcon name="question" variant="regular" />
```

## Conventions

- Use kebab-case Font Awesome `iconName` values, and omit `family` for classic icons.
- Register concrete icon definitions in `src/Utils/LGS1920IconLibrary.js` and pass them to the generic resolver in `src/Utils/useWebAwesomeKits.js`.
- The `circle-plus`, `ruler-vertical`, and `question` regular definitions are bundled from `@fortawesome/pro-regular-svg-icons`, so their availability does not depend on the remote Kit subset.
- The `arrows-up-down`, `arrows-left-right`, `lasso`, and `square-dashed` solid definitions are bundled from `@fortawesome/pro-solid-svg-icons` for Replay guide and Fix Path cursors. The glyphs are 20 × 20 CSS pixels in centered 24 × 24 cursor boxes. Replay guide icons use black with a compact dark shadow, while Fix Path icons retain their state color; both receive a white outline with a subdued gray halo.
- The `square` and `square-check` regular definitions and the `square-full` solid definition are bundled for the Fix Path tri-state point-selection indicator.
- The solid `magnifying-glass-plus`, `magnifying-glass-minus`, `arrow-rotate-left`, and `arrow-rotate-right` definitions are bundled for transient Replay joystick feedback.
- The solid `basket-shopping`, `bottle-water`, `bridge`, `bus-stop`, `cable-car`, `camera`, `droplet`, `faucet-drip`, `kit-medical`, `mug-hot`, `restroom`, `sign-post`, `snowflake`, `tent`, `train`, `triangle-exclamation`, `utensils`, and `water` definitions are bundled locally for POI category markers, independently of the remote Kit subset.
- Custom classic and duotone definitions come from `@awesome.me/kit-eb5c406148`.
- Missing local definitions delegate to Web Awesome's default resolver. Do not assume a standard icon belongs to the Kit merely because its npm package is installed.
- The implementation contract is documented in `tech-doc/specs/ui-widgets/CORE-UI-ICONS-SPEC.md`.
